# 3.10 AI on the edge
Course 3 · activity 651207 · no video

## Edge computing
- **Edge computing** = running AI on devices or servers **closer to the data source or point of need**.
- Cloud isn't always ideal. A self-driving car or a drone avoiding obstacles **can't wait for a cloud round trip**.
- **Benefits:**
  - **real-time responsiveness**;
  - **increased data privacy**;
  - **less reliance on internet connectivity**.

## Google edge tools
- **Lite Runtime (LiteRT):** Google's high-performance runtime that helps ML models **run efficiently on-device** (edge devices, phones).
- **Gemini Nano:** Google's **most efficient, compact** model, built to run on the edge (smartphones, embedded systems). Part of the Gemini family; a miniature version of the data-centre AI.
  - **Benefits:**
    - **Privacy:** data stays on the device.
    - **Speed:** no cloud round trip.
    - **Offline access:** works without internet.
  - **Where it's used:**
    - **Pixel phones:** **Call Notes** (summarises phone calls) and **Pixel Recorder** (summarises recordings).
    - **Android:** available to developers through the **AI Edge SDK**.

## Agent Platform still matters for edge
- **Build, train, refine:** data prep, training, tuning, evaluation, collaboration, MLOps.
- **Deploy to the edge:**
  1. **Convert models** to **LiteRT**.
  2. **Package and deploy** models plus dependencies in **containers** for various edge hardware.
  3. **Manage and monitor** edge deployments and gather insights to improve.

## Knowledge check: edge or cloud?
| Scenario | Answer | Reason |
|---|---|---|
| Medical device giving real-time feedback during surgery | **Edge** | Cloud latency unacceptable |
| E-commerce chatbot handling millions of queries a day | **Cloud** | Needs scale and robustness |
| Self-driving car making instant decisions | **Edge** | Split-second, on-device |
| Smart-city traffic-flow optimisation | **Cloud** | Centralised, high-capacity analysis |

## Key takeaway
Edge = local, real-time, more data control. Tools: **LiteRT, Gemini Nano**. Use **Agent Platform** to build and refine.
