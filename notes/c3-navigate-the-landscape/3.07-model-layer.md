## What is an AI model?
- The **"brain"** of any AI/ML system: sophisticated mathematical structures trained on massive data.
- They learn patterns and relationships to **generate content, analyse data, classify information**.

## Agent Platform as a model hub: build or use existing
### Use existing models: **Model Garden**
- Most organisations **don't need a new model**. Fine-tune and reuse existing ones.
- **Model Garden** (on Agent Platform) lets you **discover, customise and deploy** models from **Google and Google partners**.
- **Over 160 models**: Google, third-party and open-source. Customise with your data and deploy to your apps. Some pre-trained models work **out of the box without tuning**.

| Category | Examples named on the page |
|---|---|
| **First-party foundation models** | **Gemini** (Pro, Flash…); **Imagen** (text-to-image); **Veo** (text-to-video, image-to-video); **Chirp 2.0** (speech-to-text) |
| **First-party pre-trained APIs** | **Speech-to-Text**, **Natural Language Processing (NLP)**, **Translation**, **Vision** |
| **Open models** | **Gemma 2**, **CodeGemma**, **PaliGemma**, **Meta Llama 3.1 / 3.2**, **Mistral AI**, AI21, **TII Falcon**, BERT, FLAN-T5, ViT, EfficientNet |
| **Third-party models** | **Anthropic's Claude model family** (partner foundation models) |

### Build your own models
1. **Fully custom training** at scale with any ML framework: **PyTorch, TensorFlow, scikit-learn, XGBoost**.
2. **Agent Platform AutoML**: create and train models with **minimal technical knowledge and effort**.

| AutoML data type | Supported objectives |
|---|---|
| **Image** | Classification, object detection |
| **Video** | Action recognition, classification, object tracking |
| **Tabular** | Classification / regression, forecasting |

## Knowledge check (answer key)
- Translation for a global e-commerce platform; want a ready, high-performing option at a moderate budget → **Model Garden** (existing model or pre-trained API).
- Expert researcher building cutting-edge protein-folding prediction; needs full control of architecture and training → **Build a custom model on Agent Platform**.

## Key takeaway
The model is the core. **Model Garden** offers a large repository of pre-built models; **Agent Platform** also supports custom models (custom training or AutoML).
