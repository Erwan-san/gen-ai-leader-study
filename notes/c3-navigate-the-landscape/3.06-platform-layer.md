# 3.6 The platform layer
Course 3 · activity 651202 · video summarised

## Video
- Building ML solutions alone "in the wild" is very complex. A good platform brings all the pieces together **easily and scalably**. The platform is **"the glue"**.
- Example: Google Cloud's unified ML platform, **Vertex AI**, now called **Agent Platform**. It provides **infrastructure, pre-trained models and tools** to build, deploy and manage ML and gen AI.

## Agent Platform: 6 key features and benefits
1. **Open and flexible:** supports open frameworks, your preferred tools and models, **no vendor lock-in**.
2. **Powerful infrastructure:** Google Cloud's scalable, reliable infrastructure.
3. **Pre-trained models:** choose many, or build your own.
4. **Comprehensive tooling:** integrated tools to develop, deploy and manage.
5. **Customisation:** fine-tune and adapt models using the **built-in IDE**.
6. **Easy integration:** put models into apps via **APIs**.

## MLOps on Agent Platform
- Operationalising training is hard (infrastructure, security). Agent Platform gives you:
  - **fully managed compute**;
  - **high-performance, ML-optimised training jobs**;
  - **distributed training**;
  - **hyperparameter optimisation**;
  - **enterprise security**.
- **MLOps** automates, standardises and manages the ML project lifecycle, which improves collaboration and continuous improvement.
- MLOps capabilities: orchestrate end-to-end workflows, feature engineering, experiments, manage and iterate models, track ML metadata, monitor and evaluate quality.

| MLOps tool | Purpose |
|---|---|
| **Agent Platform Feature Store** | **Share, serve and reuse ML features** for consistency and efficiency |
| **Model Registry** | **Manage model versions**, track changes, organise models across the lifecycle |
| **Model Evaluation** | **Evaluate and compare** model performance to pick the best |
| **Agent Platform Pipelines** (workflow orchestration) | **Automate ML workflows** from preprocessing to deployment |
| **Model Monitoring** | Detect **performance degradation, input skew and drift**; trigger updates or **retraining** |

## Knowledge check (answer key)
- Track experiments, manage versions, keep a change record → **Model Registry**.
- Deployed model's performance declining; find the cause and retrain → **Model Monitoring**.
- Automate the whole pipeline from preprocessing to deployment → **Agent Platform Pipelines**.

## Key takeaway
The platform (Vertex AI / Agent Platform) simplifies ML through a unified platform, comprehensive tooling and **MLOps**.
