§1 · 30%Fundamentals of gen AI

Nesting

AI (machines doing tasks that need human intelligence) ⊃ ML (learn from data) ⊃ Deep learning (multi-layer neural networks) → Foundation models (huge, diverse data; adaptable) → LLMs (language) · Diffusion models (refine noise into images, audio, video).

Gen AI = creates new content. NLP = understand and generate human language. Multimodal = several data types combined.

Learning types

Supervisedlabeled data → predict (spam filter, house prices)
Unsupervisedunlabeled → find groupings (segments, topics)
Reinforcementtrial and error, rewards/penalties
Semi-supervisedsmall labeled + large unlabeled

§3 · 20%Techniques to improve output

Limitations → fixes

Limitations: data dependency · knowledge cutoff · bias · fairness · hallucinations · edge cases.

Fixes: grounding · RAG · prompt engineering · fine-tuning · humans in the loop.

Which fix?

Quick improvementprompt engineering
Fresh or private facts, citationsRAG / grounding
Consistent style, format, behaviourfine-tuning (prompt tuning = lightweight variant)
High stakeshuman in the loop

Prompting

Zero-shot (no examples) · one-shot · few-shot · role prompting (persona) · prompt chaining (steps build on each other) · chain-of-thought (step-by-step reasoning) · ReAct (reason + act with tools: think → act → observe → respond) · metaprompting (AI writes prompts) · system instructions.

Grounding

Sources: first-party enterprise data · third-party data · world data (Google Search).

RAG = retrieve → augment prompt → generate. Offerings: pre-built RAG with Agent Search · RAG APIs · Grounding with Google Search.

§4 · 15%Business strategy, secure and responsible AI

Strategy

Top-down (leaders: vision, funding, ethics) + bottom-up (managers and ICs: use cases, experiments). Start low-risk; prioritise feasible, actionable, affordable, high-ROI.

6 steps: clear vision · high-impact use cases · invest in capabilities · drive change · measure value · champion responsible AI. Impact: define metrics → collect data → iterate.

People and needs

Augment strategic work, automate repetitive work; humans stay in the loop.

Needs: scale · customisation · user interaction · privacy · latency · connectivity · accuracy · explainability. Factors: business requirements + technical constraints.

Cost: training · deploying · using. Pricing by usage (tokens, characters, requests, compute time), subscription, licence, free tier.

Secure AI (intentional harm)

Data poisoning · model theft · adversarial attacks / prompt injection. Protect every lifecycle stage.

SAIF (Secure AI Framework) · secure-by-design infrastructure · IAM · Security Command Center · workload monitoring · Mandiant.

Responsible AI (intentional + unintentional)

Built on security. Transparency · privacy (anonymization = can't link back; pseudonymization = re-linkable with a protected key) · data quality, bias, fairness · accountability and explainability · legal (privacy, non-discrimination, IP, liability).
