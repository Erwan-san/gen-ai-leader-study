## ReAct ("reasoning and acting")
- **Definition:** a prompting framework that lets the model **reason AND take action** on a user query, **with or without in-context examples**.
- Analogy: it gives the LLM "a brain and a pair of hands". A step up from passive text generation.
- **Loop: Think → Act → Observe → Respond** (thought–action–observation):
  - **Think:** produce a thought about the problem (like CoT).
  - **Act:** choose an action (web search, database, a tool) and **specify its input** (query, command).
  - **Observe:** receive the result (search results, database rows).
  - **Respond:** answer the user, act further, or form a new thought for the next iteration.
- Mechanically, the agent asks the model for the next step, which can contain a **thought, action (tool choice), action input, observation**.
- **Why it matters:**
  - **Dynamic problem solving** with external resources and new information;
  - **reduced hallucination** (reasoning grounded in real data);
  - **increased trustworthiness** (visible reasoning and source interaction).
- **Applications:**
  - **question answering** with external knowledge;
  - **fact verification** by searching for evidence;
  - **decision making** in interactive environments.

## Chain-of-thought (CoT)
- **Definition:** guide the model through problem-solving with **examples that include intermediate reasoning steps**, so it learns a structured, logical approach. "Teaching the LLM to think out loud."
- Related to prompt chaining, but done **behind the scenes** for the user.
- **Why it matters:**
  - **improved reasoning** on logic-heavy problems;
  - **better accuracy** by breaking problems into steps;
  - **enhanced explainability** (trust and transparency).
- **Variants:**
  - **Self-consistency:** generate several solutions and choose the most consistent.
  - **Active-prompting:** the LLM asks **clarifying questions** or requests more information.
  - **Multimodal CoT:** combine text with images or video.
- **Applications:**
  - complex reasoning (math word problems, logic puzzles);
  - **explanation generation**;
  - **multi-step planning** (a story, a trip, debugging code).

## Choosing
- **CoT = internal reasoning. ReAct = external interaction** (gather information, take actions).
- They can be **combined** for deep reasoning plus dynamic interaction. Many other frameworks exist; choose per use case.
