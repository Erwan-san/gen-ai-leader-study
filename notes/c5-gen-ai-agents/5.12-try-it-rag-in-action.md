# 5.12 Try it: RAG in action
Course 5 · activity 646174 · hands-on lab

## Lab steps (Google AI Studio)
1. Log in to Google AI Studio and select **Try Gemini**.
2. In **Run settings**, select the model **Gemini 2.5 Flash**.
3. Prompt something time-sensitive, e.g. "What are the latest trends in generative AI?", then **Run**.
4. **Run settings → Tools →** toggle **Grounding using Google Search**. Rerun the same prompt.
5. Compare the two answers. The grounded one should be **more current and relevant**, with sources.

## Key takeaway
**Grounding with Google Search** (RAG on real-time web data) makes answers **more accurate and up to date** than training data alone.
