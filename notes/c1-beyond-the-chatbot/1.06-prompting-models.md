# 1.6 Prompting models
Course 1 · activity 638555 · no video

## Key points
- Foundation models take **inputs called prompts** and produce **outputs**.
- Every AI model has inputs, but many have **strict input requirements**: only numbers, only emails, only images.
- Foundation models, and especially **multimodal** ones, accept a much **broader set of inputs**.

## Input → output examples
| Input (prompt) | Output |
|---|---|
| A question | The answer |
| A text description requesting an image | The image |
| A request to summarise a file | The summary |
| Sample code with errors | Corrected code |

## Terminology
- **Prompting = prompt engineering = prompt design.** Writing prompts is "an art and a science", with many techniques.
- Prompting is **one of the most important skills** for getting value from gen AI models and tools.

## Key takeaway
Foundation models are accessed through prompting. Effective prompts unlock text generation, translation, creative content and informative answers.
