# 3.12 Gen AI solution needs
Course 3 · activity 651209 · no video

Assess needs before starting: align ambitions with capabilities.

## 1. Scale
- **Small scale** (individual or small team): go far with **pre-built tools** and existing gen AI apps.
- **Large scale** (millions of customers): needs a more **robust, customised** solution with **scalability and security**. Factor in **infrastructure cost, data storage, latency**.

## 2. Customisation
Foundation models keep improving, so **custom model development is less often necessary**.
- **Start with existing models:** pre-trained models via **APIs or open-source libraries**; **fine-tune** on your data.
- **Identify unique needs:** specialised knowledge, complex tasks, or a unique UX determine the customisation level.
- **Consider data specificity:** specialised domains (**law, medicine**) → fine-tune with domain data or use domain-trained models.
- **Consider task complexity:** simple (summarisation) vs intricate (code generation, creative writing) affects model choice and training.

## 3. User interaction
- **UI:** integrate into existing workflows: a dedicated interface (e.g. a **chatbot widget**) or embedded in current apps.
- **UX:** user-friendly; conversational, informative or task-oriented? How much guidance and feedback do users need?

## 4. Privacy
- **Data security:** protect data in processing and storage (**encryption, access controls, secure data centres**).
- **Compliance:** regulations such as **GDPR, HIPAA**.

## 5. Other considerations
| Factor | Question | Tip |
|---|---|---|
| **Latency** | Acceptable response time? | If real time isn't critical, you have more flexibility in model and infrastructure |
| **Connectivity** | Always online? | Plan **offline** functionality if needed (→ edge) |
| **Accuracy** | How crucial? What error tolerance? | Defines model selection, training data, evaluation metrics |
| **Explainability** | Need the reasoning behind decisions? | Use explainable models or techniques, especially in **healthcare and finance** |

## Knowledge check
- Scenario: realistic images from text for a marketing campaign; some coding skills; **short on time**.
- Options: pre-trained API / build from scratch / fine-tune a Model Garden text-to-image model.
- My answer key: **use a pre-trained API**, the fastest path. Building from scratch is clearly wrong. Fine-tuning costs time you don't have.

## Key takeaway
Assess **scale, customisation, user interaction, privacy**, plus **latency, connectivity, accuracy, explainability**.
