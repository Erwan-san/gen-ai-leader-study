# 4.7 Reusing prompts with Gemini and Gems
Course 4 · activity 646199 · video summarised

> **Partial gap:** the interactive "prompt chaining scenario" (marketing manager, organic skincare campaign) is a click-through dialogue that wasn't captured as text.

## Video
- After experimenting you'll know where the tools shine and where you need something **more tailored**. Examples: you're tired of retyping long prompts, or you need gen AI in a more complex workflow.
- You can **customise and automate without writing code**.

## Levels of reuse (simple → more tailored)
### 1. Prompt templates
Save reusable prompts in a **Google Doc or Sheet**. Templates by role on the page:
- **Marketing manager:** social post for [platform] promoting [product], highlighting [benefits], with a call to action.
- **Content writer:** a [content type] about [topic] for [audience], in a [tone], including [keywords].
- **Customer support:** reply to [email], empathetic, addressing [issue], with a solution in line with [company policy].
- **Software developer:** Python code to [task] using [libraries], following [style guidelines].

### 2. Prompt chaining in one thread
- Keep working in the **same conversation** so history carries over.
- Gemini lets you **name and pin chats**.

### 3. Gemini Advanced
- An upgraded Gemini, more capable for complex tasks: **coding, logical reasoning, nuanced instructions, creative collaboration**.
- You can set **data retention** and **delete conversation history** at any time.

### 4. Saved info
- Persistent facts that Gemini **always uses across all chats**. Set in **Settings**.
- Use it when you want context remembered **without the full conversation history** influencing answers.
- **Examples:**
  - A **sales rep** saves "I'm a sales rep" and practises pitches without feedback being skewed by earlier sessions.
  - A **sales team leader** saves targets, **KPIs** and report format for weekly reports.

### 5. Gems
- **Task-specific** context when Saved info (which applies to **all** chats) is too broad.
- Like agents, they process information and reason **within the context of a chosen task**.
- **Examples:**
  - **Creative writing Gem:** your style, tone, resources; brainstorming and feedback.
  - **Coding Gem:** favourite libraries, conventions, documentation; debugging and snippets.
  - **Marketing Gem:** audience demographics, competitor info, campaign data; ideas, copy, performance analysis.

## Knowledge check: prompt chaining vs Saved info vs Gem (my answer key)
| Scenario | Best strategy |
|---|---|
| Social media manager needing a consistent brand voice across platforms | **Gem** |
| Sales rep practising pitches, wanting independent feedback each time | **Saved info** (matches the page's own example) |
| Developer who only wants snippets in one specific language | **Gem** (or Saved info if it applies to all their chats; the page frames Gems as task-specific) |
| Writer brainstorming a creative project and getting feedback | **Prompt chaining** |
| Dog groomer wanting all self-care questions answered about dogs | **Saved info** (applies to every chat) |

## Key takeaway
Reuse well-crafted prompts. Use **chaining** for in-conversation context, **Saved info** for global persistent context, **Gems** for task-specific assistants.
