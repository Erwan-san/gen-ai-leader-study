# 5.10 Building applications from your agents
Course 5 · activity 646171 · video summarised

## From prototype to app (video)
- After tuning prompts and parameters in AI Studio or Agent Studio, you integrate the model into your own apps.
- **Credentials:**
  - **Google AI Studio** → generate an **API key**.
  - **Agent Studio** → set up **authentication and authorisation** (Google Cloud).
- Analogy: a **backstage pass**. Proper authorisation gives secure, controlled access.
- Then your code makes **API calls** that send the **prompt plus parameters** and receive generated output.

## Where to run it
| Option | What | Example |
|---|---|---|
| **Cloud Run functions** | Small pieces of code in the cloud, **triggered by events** (image upload, new message). **No servers to manage** | Auto-caption uploaded images with Gemini |
| **Cloud Run** | Runs apps in **containers** (self-contained packages with everything needed). Easy deploy and scale; suits complex apps needing specific software or configuration | Host a web app with a Gemini-powered chatbot |
| **Anything that can make HTTP requests** | Web, mobile, desktop, even **embedded systems** | |

## No-code / low-code
- **Apps Script:** a cloud platform for **automating Google Workspace** with JavaScript plus built-in services. Use the Gemini API to build **Workspace add-ons**.
- **AppSheet:** a **no-code** platform for custom business apps. Extend it with Apps Script or APIs; with the Gemini API you can automate tasks, generate content, add assistance inside the app.

## Multi-agent applications
- Several **specialised agents** together make the app more efficient and capable. They work independently or interact.
  - Example: a travel app with a flights agent, a hotels agent and an attractions agent.
- Benefits: **modular → efficiency, flexibility, scalability**.
- **An agent can be a tool of another agent.** E.g. a **sentiment-analysis agent** used by a **customer-service agent** to gauge satisfaction.

## Key takeaway
Integrate via **APIs, Cloud Run functions, Cloud Run, Apps Script, AppSheet**. Use **multi-agent systems** for complex apps.
