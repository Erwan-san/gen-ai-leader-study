## Options
- Custom-build tools, use **third-party** tools, or use **Google Cloud**.
- Many Google Cloud tools work **even if the core agent logic is built outside Google Cloud**.

## Key Google Cloud services for agent tooling
| Service | Use as a tool |
|---|---|
| **Cloud Storage** | Highly scalable, durable **object storage** for the data agents need |
| **Databases: Cloud SQL, Spanner, Firestore** | Store and retrieve information, user data, track agent progress |
| **Cloud Run functions** | **Serverless functions** as specialised tools: connect to databases, call external APIs, do calculations. Triggered by the agent, **auto-scale** |
| **Cloud Run** | **Serverless platform for stateless containers**, for complex custom tools with specific dependencies or more control |
| **Agent Platform** | **Agents can use other agents as tools.** Create models or agents that other agents call |

## Pre-built AI APIs
| API | Capability |
|---|---|
| **Speech-to-Text** | Speech → text (meetings, support calls, video) |
| **Text-to-Speech** | Text → natural speech (voice UIs, personalised communication) |
| **Translation** | Text, documents, websites, even audio and video, into **135+ languages** |
| **Document Translation** | Translates formatted documents **keeping the layout** |
| **Document AI** | **Extract data** from documents (invoices, contracts, medical records); automate capture and processing; can **summarise large documents with gen AI** |
| **Cloud Vision** | Detect objects, faces, landmarks; **OCR**. Image tagging, content moderation, visual search |
| **Cloud Video Intelligence** | Find objects, actions and events in video; transcribe speech. Recommendations, video search, media analysis |
| **Natural Language** | **Sentiment**, content classification, **entity extraction** (people, places, events); multilingual |
| **Other** | The **API Library**: Google Maps, Workspace, YouTube, Google Photos and more |

## Example: meeting location planner
- **Scenario:** a user uploads a meeting invitation or a list of venues and asks for the most convenient location.
- **Flow:**
  1. **Document AI** extracts the addresses.
  2. The **Google Maps API** analyses the locations.
  3. The agent recommends a venue from **unstructured data**.

## Key takeaway
**Orchestrate multiple tools** (Cloud Run functions, databases, pre-built APIs such as Document AI and Maps) for complex multi-step tasks.
