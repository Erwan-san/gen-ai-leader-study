# 5.17 Build your own agent
Course 5 · activity 646179 · hands-on lab

## Agent instructions in CX Agent Studio
- Define the agent's **goal** (support, Q&A, creative content), **how it should act**, and **rules** to follow.
- Add **tools** such as **data stores**.
- Then **test and interact**.

## Lab: Cymbal Manufacturing chatbot (built in Google AI Studio)
- **Why AI Studio here:**
  - **CX Agent Studio would normally be recommended** for a customer chatbot, but it needs a Google Cloud account and project.
  - AI Studio teaches the concepts without infrastructure.
  - For production-grade agents (e.g. **adversarial defence**), use CX Agent Studio.

### System instructions
Provide **context, persona and constraints before any user input**. Four benefits:
1. **Consistency:** stable tone and persona.
2. **Accuracy:** grounded in specific knowledge, fewer hallucinations.
3. **Relevance:** stays in the intended domain.
4. **Safety:** avoids inappropriate or unhelpful output.

### Steps
1. **Set up:**
   - aistudio.google.com → **Chat with models** → Run settings → model **Gemini 2.5 Flash**.
2. **Create an "Agent instruction writer":**
   - **Enable saving** (grant Google Drive access).
   - Open **System instructions** and create one titled "Agent instruction writer".
   - Its content: a persona that is an expert at building virtual assistants and writes a system prompt (goal plus instructions) for a given company and role.
3. **Generate the chatbot's system prompt:**
   - Give the writer the use case:
     - Cymbal mainly builds **storage containers**, and also does **custom machining** on request (users must **call the company**).
     - Answer reasonable container questions **without over-guessing**.
     - Containers are usually **blue or green**, occasionally **red**.
     - **Respectful tone**; **admit when you don't know**.
     - Phone **(333) 333-3333**.
   - **Copy** the output.
4. **Create the chatbot:**
   - **New chat** → **Create new instruction** → "Cymbal Manufacturing chatbot".
   - Paste the generated system instructions.
5. **Test:** say hello; ask about colour or size; ask about custom manufacturing; ask something off-topic (the weather).

## Metaprompting
- Steps 2–3 used **metaprompting**: prompts that guide AI to **generate, modify or interpret other prompts**.
- A key technique for dynamic, flexible, adaptable prompting.

## Key takeaway
In **CX Agent Studio**, you write agent instructions and link **tools like data stores**. AI Studio was used here only for accessibility.
