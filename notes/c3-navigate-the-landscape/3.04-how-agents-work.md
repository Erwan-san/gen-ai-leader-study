# 3.4 How agents work

## Two categories of agents
### Conversational agents
They understand **what you mean, not just what you say**, and respond naturally. Flow:
1. **You provide input:** typed or spoken.
2. **The agent understands:** AI infers meaning and **intent**.
3. **The agent calls a tool:** if needed, to get information or act (web search, database, another app).
4. **The agent generates a response:** relevant and natural.
5. **The agent delivers the response:** shown or spoken, matching how you interacted.

Examples:
- **Answering questions:** asked about the weather in Paris, the agent gives the current temperature, the forecast and packing tips.
- **Casual conversation:** the agent tells jokes or discusses your favourite books and movies.
- **Accessing information:** the agent draws on world knowledge for concise answers, e.g. the capital of Australia or a summary of the French Revolution.

### Workflow agents
They streamline work by **automating tasks or complex processes** efficiently and correctly. Flow:
1. **You define a task or trigger a process:** submit a form, upload a file, a scheduled event, an online order.
2. **The agent interprets the requirements** and defines the series of steps.
3. **It executes actions** per the workflow definition: data transformation, file transfer, notifications, external system integration, other automations via **APIs**.
4. **It generates a result:** a report, data file, confirmation, or status update.
5. **It delivers the result** to recipients or systems: email, dashboard, database, file storage.

Examples:
- **E-commerce order fulfilment:** the agent processes orders, updates inventory, sends shipping notifications and handles returns.
- **Customer onboarding:** the agent guides new customers through account setup, provides tutorials and answers FAQs.
- **Automated research:** the agent browses the web on its own, summarises relevant content and writes a full report. Try it with **Gemini Deep Research**.
- **Security log parsing:** the agent inspects incoming security logs, flags anomalies, opens a ticket, starts triage and assigns cases to humans for review when needed.

## Agent use-case families (both types)
| Type | Does |
|---|---|
| **Customer service agents** | Answer questions, resolve issues, personalised recommendations |
| **Employee productivity agents** | Find information, manage tasks, automate workflows |
| **Creative agents** | Generate ideas and content, translate |
| **Code agents** | Help developers write, review and debug code; generate code from natural-language descriptions |
| **Data agents** | Analyse large datasets, find trends, extract insights |
| **Security agents** | Summarise cases, research threats, generate security queries, create **detection rules** |

## Key takeaway
**Conversational** = dialogue with users. **Workflow** = automate multi-step tasks.
