# 1.7 Prompting the Gemini app
Course 1 · activity 638556 · contains a short demo video (summarised)

## Demo (video)
- In the **Gemini app** (gemini.google.com), you type the prompt in the text box at the bottom, like a conversation with an assistant.
- You can ask questions, give creative tasks, or ask for summaries of complex information.
- **Demo prompt:** a poem on why employees should attend the company-wide meeting. You press Enter and Gemini returns a unique poem.

## Hands-on activity (mapped to the four uses)
- **Create:** ask for website text for your product.
- **Summarize:** ask for a summary of a long work document or email.
- **Discover:** ask it to research a topic.

## Knowledge check: which input type gives this output?
Input types listed: text description, image input, code snippet, audio file, video file.
| Desired output | Input needed |
|---|---|
| Realistic image of a futuristic cityscape | **Text description** (describe the city) |
| Fixed version of a buggy Python script | **Code snippet** (paste the code plus the request) |
| Summary of troubleshooting steps from a customer-service call | **Audio file** (call recording plus the request) |
| Personalised workout plan | **Text description** (goal plus fitness level) |

## Key takeaway
Prompting is a skill built through **practice and experimentation**.
