# 2.6 Turning data into learning using Google Cloud
Course 2 · activity 607915 · no video

## Context
- Going from scattered data to insight takes several steps. For enterprises, also consider **security, robustness and scalability**.
- Google Cloud provides data and ML tools across the **entire ML lifecycle**.

## The ML lifecycle: 5 stages and their Google Cloud tools (exam favourite)
| Stage | What it is | Google Cloud tools |
|---|---|---|
| **1. Gather your data** (data ingestion) | Collect raw data from sources; decide what's needed from the desired outcome | **Pub/Sub**: real-time **streaming**, any structure. **Cloud Storage**: **unstructured** data. **Cloud SQL** and **Spanner**: **structured** data. |
| **2. Prepare your data** | Clean and transform into a usable format; formatting and **labeling** | **BigQuery**: analysis; filter, fix inconsistencies, handle missing values. **Data Catalog**: **governance**; a central repository to **discover datasets** across the org. |
| **3. Train your model** | Create the ML model from data | **Gemini Enterprise Agent Platform**: managed training environment, set parameters, **prebuilt containers** for popular frameworks, **custom training jobs**, **model evaluation** tools, powerful compute for faster training |
| **4. Deploy and predict** | Make the trained model available for use | **Agent Platform**: serve predictions and **scale** resources to demand |
| **5. Manage your model** | Maintain models over time | **Versioning**. **Performance tracking** (metrics). **Drift monitoring** (accuracy changes over time). **Data management** with **Agent Platform Feature Store** (manages model features). **Storage** with **Model Garden** (store and organise models). **Automation** with **Agent Platform Pipelines** (automate ML tasks). |

## Cross-cutting
- The tools **work together** and connect to existing or custom tools.
- Google Cloud infrastructure provides **availability and reliability**.
- **Identity and Access Management (IAM)** keeps data safe: only the right people get access.

## Key takeaway
Lifecycle = **ingestion & preparation → training → deployment → management**. Agent Platform handles training and deployment; the data tools handle ingestion, preparation and management.

## Exam hooks
- Matching questions: streaming → Pub/Sub; unstructured storage → Cloud Storage; structured → Cloud SQL / Spanner; dataset discovery and governance → Data Catalog; features → Feature Store; automate ML workflow → Pipelines; drift → model management.

## Exam wording & corrections
- Course says 'store models in Model Garden'. Precise: **Model Registry** manages your own model versions; **Model Garden** is where you discover, customise and deploy available models.
- **Data Catalog** was discontinued on 1 June 2026 and replaced by **Knowledge Catalog** (formerly Dataplex Universal Catalog). The exam guide doesn't name either.
