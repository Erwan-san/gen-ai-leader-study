# 3.2 Understanding the layers of gen AI
Course 3 · activity 651197 · video summarised

## The 5 layers (top → bottom) — exam core
| Layer | Role | Key points |
|---|---|---|
| **Gen AI powered applications** | The user-facing **frontend** | Where users interact with and use AI capabilities. The layer most people know. |
| **Agents** | **Autonomous action** | An **agent** is software that **learns how best to achieve a goal from its inputs and the tools available**. It independently sets goals and carries them out in a defined environment: analyses situations, uses multiple tools, decides without constant human input. Handles **multi-step tasks a model alone can't** (research a topic, troubleshoot code, access a system by chaining actions). Types: customer, code, data agents and more. |
| **Platform** | The "backbone" or "glue" | Sits **between agents and models**, above models and infrastructure. Provides **APIs, data management, model deployment tools**. Hides infrastructure complexity. |
| **Models** | The agent's **"brain"** | Complex algorithms trained on vast data. They learn patterns to generate content, translate, answer questions. |
| **Infrastructure** | The **foundation** | Core compute: physical hardware (**servers, GPUs, TPUs**) and software to store and run models and training data. |

## Analogy: gen AI as an engine (recap)
- Infrastructure = **foundation**
- Models = **core**
- Platform = **connects everything**
- Agents = **drivers** (decide and act)
- Applications = **vehicles** (take us to the destination)

## Key takeaway
Leaders should understand the interplay between the layers to guide teams, make informed decisions and unlock gen AI value.

## Exam wording & corrections
- The course says agents 'independently set goals'. In practice an agent pursues a goal it is given, deciding its own steps and tools.
