# Gen AI Leader Study

Personal study site for the Google Cloud **Generative AI Leader** certification learning path (5 courses, 70 lessons).

- `index.html` — the site: course tree with seen-tracking, lesson notes with the course videos playing in the page, spaced-repetition flashcards (384 cards), progress stats. Progress is stored in the browser.
- `notes/` — lesson study notes (own-words summaries) in Markdown.
- `cards.json` — flashcard deck. `videos.json` — YouTube video IDs per lesson.

Not affiliated with Google. Course content and videos belong to Google Cloud; the videos are embedded from YouTube.
