# 5.4 Google's generative AI APIs (Google AI Studio vs Agent Studio)
Course 5 · activity 646165 · demo video summarised

## Google's gen AI APIs
- **Pre-trained LLMs** that can be **fine-tuned**.
- **Capabilities:** **text completion, multi-turn chat, code generation, image generation**. E.g. the **Nano Banana API** generates and customises images.

## Two places to experiment
| Attribute | **Google AI Studio** | **Agent Studio** (on Gemini Enterprise Agent Platform; formerly Vertex AI Studio) |
|---|---|---|
| What | **Web-based** tool to try Gemini models and start building with the **Gemini Developer API** | **Google Cloud console** tool to **rapidly prototype and test** gen AI models: test with prompt samples, **design and save prompts**, **tune foundation models** |
| Focus | Streamlined, easy interface: explore Gemini, experiment with parameters, creative text | **Comprehensive, robust** environment to build, train and deploy ML models (part of Agent Platform) |
| Users | **Beginners, hobbyists, early-stage** development (incl. non-technical users) | **Professionals, researchers, developers** |
| Access | **Standard Google account** | **Through Google Cloud** |
| Limitations | **Usage limits** (queries, requests and tokens per minute). For **prototyping and small-scale** use, not production | **Service charge based on usage** |
| Advantages | Simple and easy to start | **More flexible quotas** (can be raised on request); **enterprise-grade security and compliance** |

**Rule:** starting out → **Google AI Studio**. Scalable, professional, production → **Agent Studio**.

## Google AI Studio demo (video)
- Explore Gemini models or **"vibe code" apps**. Prompt as in the Gemini app.
- Add **system instructions** to set the agent's overall tone and style.
- **Right pane:**
  - choose the model or agent;
  - set sampling parameters: **temperature, thinking level, top-P**;
  - **safety settings**;
  - tools: **function calling**, **structured output**, **grounding with Google Search**.
  - Options vary by model.
- Test by trying prompts.
- It's also a prototyping environment that **builds apps from natural-language descriptions**.
- **Get code** to run in your own app. This requires creating an **API key**.
- Generated code is for **small-scale projects and prototypes**. For large enterprise projects use **Agent Studio**.

## Key takeaway
**AI Studio** and **Agent Studio** let developers and non-technical users experiment with gen AI APIs and customise models.

## Exam wording & corrections
- The APIs are interfaces; the models behind them are pre-trained (and tunable).
