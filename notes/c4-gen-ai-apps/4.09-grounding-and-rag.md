# 4.9 Grounding and RAG
Course 4 · activity 646201 · no video

## Grounding (no-code)
- **Grounding** = the AI model's ability to **connect its output to verifiable, specific sources**. It's critical for **trust and reliability**.
- You already do it without code when you **attach resources to a Gem**, or **attach documents in Gemini app prompts** (with Gemini Advanced).
- **Example:** give Gemini your company **style guide** (in the prompt or as an upload) so it edits text to your organisation's standards.
- Richer context → more accurate, insightful results.

## RAG (retrieval-augmented generation)
1. **Retrieve** relevant information from a knowledge base (database, documents, even the whole web). This is often powered by **semantic search** or **vector databases**.
2. **Generate** the output using what was retrieved.

| | Model only (no RAG) | Model with RAG |
|---|---|---|
| Flow | User prompt → model output | Query goes to a **backend retrieval system** (vector DB or search engine); relevant information is **embedded in the prompt** → model output |
| Knowledge | No external knowledge; possibly **outdated** | **Latest external knowledge** |
| Hallucination risk | **Higher** | **Much lower** |

## RAG benefits (memorise the three)
1. **Improved accuracy and relevance.**
2. **Improved explainability and transparency:** shows the **specific sources**, so claims can be checked.
3. **Extending LLM capabilities:** can **constrain** the output to the provided context.

RAG lets models go beyond memorising to **accessing and using external knowledge**.
